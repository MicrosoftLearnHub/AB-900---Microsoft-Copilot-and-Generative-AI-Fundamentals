## 📝 10 Realistic Demo Practice Questions & Answers

### Question 1 (Domain: Generative AI Concepts)
**Scenario / Question:** What is the primary function of a Large Language Model (LLM) in generative AI?
- A) Predicting the most statistically probable next token (word or sub-word) based on learned patterns from massive text datasets
- B) Storing relational tables in a SQL database
- C) Compiling C# source code to bytecode
- D) Scanning hard drives for computer viruses
- **Correct Answer:** **A**
- **Detailed Explanation:** LLMs are probabilistic neural networks trained to generate human-like text by predicting the next most likely token in a sequence given the input context.

---
### Question 2 (Domain: Prompt Engineering)
**Scenario / Question:** You are writing a prompt for Microsoft Copilot to draft a proposal. Which component provides the model with background details, audience specifications, and situational constraints?
- A) Context
- B) Random numbers
- C) SQL connection string
- D) Hardware IP address
- **Correct Answer:** **A**
- **Detailed Explanation:** Context provides the essential background, perspective, and constraints (audience, scenario, goal) that guide the AI to generate a tailored and relevant output.

---
### Question 3 (Domain: Copilot Ecosystem)
**Scenario / Question:** Which Microsoft AI tool provides AI-powered code suggestions, real-time code generation, unit test creation, and debugging directly inside developer IDEs like Visual Studio and VS Code?
- A) GitHub Copilot
- B) Copilot in Excel
- C) Microsoft Paint
- D) Azure Bastion
- **Correct Answer:** **A**
- **Detailed Explanation:** GitHub Copilot acts as an AI pair programmer inside IDEs, offering inline code completions and conversational coding assistance.

---
### Question 4 (Domain: Responsible AI)
**Scenario / Question:** Which Microsoft Responsible AI principle ensures that AI systems treat all demographic groups of people equally without discrimination or unfair bias?
- A) Fairness
- B) Speed
- C) Profitability
- D) Portability
- **Correct Answer:** **A**
- **Detailed Explanation:** Fairness dictates that AI systems should treat all people fairly and avoid allocating opportunities or resources in a discriminatory manner.

---
### Question 5 (Domain: Data Privacy)
**Scenario / Question:** When employees use Microsoft Copilot with commercial data protection, what happens to their chat prompts and uploaded company data?
- A) Prompts and data are protected within the enterprise boundary, are not logged or viewed by Microsoft, and are NEVER used to train the underlying foundation models
- B) They are published to public search engines
- C) They are sent to third-party advertisers
- D) They overwrite the company website
- **Correct Answer:** **A**
- **Detailed Explanation:** Commercial data protection ensures user prompts and organizational data are encrypted, not retained, and never used to train public foundation models.

---
### Question 6 (Domain: Prompt Engineering Techniques)
**Scenario / Question:** What is the prompt engineering technique where you provide one or more explicit examples of the desired input and output format directly within the prompt before asking the model to perform the task?
- A) Few-Shot Learning (Few-Shot Prompting)
- B) Zero-Shot Prompting
- C) Fine-Tuning
- D) Pre-training
- **Correct Answer:** **A**
- **Detailed Explanation:** Few-shot prompting supplies a few concrete examples of expected input/output patterns to guide the model's response formatting and reasoning.

---
### Question 7 (Domain: Copilot in M365)
**Scenario / Question:** Which Microsoft 365 Copilot experience operates across your entire work universe (emails, calendar, chats, documents, meetings) to summarize missed discussions and prepare executive briefings?
- A) Microsoft 365 Chat (Business Chat / Copilot in Teams)
- B) Notepad
- C) Windows File Explorer
- D) Device Manager
- **Correct Answer:** **A**
- **Detailed Explanation:** Business Chat connects to Microsoft Graph to synthesize information across multiple apps, emails, chats, and meetings.

---
### Question 8 (Domain: Copilot Studio)
**Scenario / Question:** Which low-code platform in the Microsoft ecosystem enables organizations to build custom generative AI copilots and extend Microsoft 365 Copilot with custom enterprise knowledge?
- A) Microsoft Copilot Studio
- B) Windows Paint
- C) WordPad
- D) PowerShell ISE
- **Correct Answer:** **A**
- **Detailed Explanation:** Microsoft Copilot Studio is the central platform for authoring, customizing, and publishing custom copilots and AI agents.

---
### Question 9 (Domain: AI Concepts (Grounding))
**Scenario / Question:** What does the term 'Grounding' mean in the context of generative AI systems like Microsoft 365 Copilot?
- A) Connecting the language model to verifiable, real-time enterprise data sources (e.g., SharePoint, emails, web search) so its responses are factually accurate and relevant
- B) Turning off the computer power
- C) Resetting user passwords
- D) Compressing video files
- **Correct Answer:** **A**
- **Detailed Explanation:** Grounding anchors the model's outputs in authentic, up-to-date business data and documents, mitigating hallucinations and ensuring factual accuracy.

---
### Question 10 (Domain: Small Language Models (SLMs))
**Scenario / Question:** Which Microsoft family of highly capable Small Language Models (SLMs) is designed for high efficiency, low memory footprint, and high-quality performance on edge devices and cost-sensitive applications?
- A) Microsoft Phi (e.g., Phi-3 / Phi-3.5)
- B) MS-DOS
- C) Windows Server
- D) Microsoft Access
- **Correct Answer:** **A**
- **Detailed Explanation:** Microsoft's Phi family of small language models achieves state-of-the-art reasoning and language capabilities while running efficiently on smaller compute footprints.
